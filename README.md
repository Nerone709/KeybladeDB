# KeybladeDB
KeybladeDB is a project that aims to research, via webapp, information relating to video games over the years, up to the year 2024. The project was made for the Database II Exam at University of Salerno. As you can see in the next image, the user can search videogames by genre, years etc. :

# Installation Guide
You can download the repo via terminal command doing:
```
git clone https://github.com/Nerone709/KeybladeDB.git
```
Or simply downloading the project as a Zip file. After the download navigate using the terminal into the folder, and write the following command:
```
pip install -r requirements.txt 
```
Remind to have python3 installed in your OS. The operation is the same for Windows, Linux and MacOS.
